# Formula 1 Interactive Dashboard (1950–2022)

## 📌 Overview
This project is an interactive Formula 1 dashboard built using **Tableau** and **Excel** to visualize race data from 1950–2022. It highlights key insights such as Grand Prix winners, fastest laps, and championship standings, enabling users to explore the history of F1 in a dynamic and engaging way.

## 📌 Features
- Year-wise Grand Prix results and winners  
- Fastest lap records and comparisons  
- Championship standings visualization  
- Historical insights across decades  
- Interactive filters for teams, drivers, and seasons  

## 📌 Tech Stack
- **Tableau** – Dashboard design & interactivity  
- **Excel** – Data cleaning, wrangling, and preprocessing  

## 📌 Dataset
- Formula 1 race results and statistics from 1950–2022  
- Data was cleaned, transformed, and structured for visualization  

## 📌 Usage
1. Open the Tableau dashboard (`.twbx` file provided)  
2. Explore year-wise or driver/team-wise stats  
3. Use filters to compare across seasons and uncover insights  

## 📌 Key Insights
- Identify top-performing drivers and constructors  
- Analyze decade-wise trends in wins and fastest laps  
- Compare rivalries and track dominance over the years  

## 📌 Future Improvements
- Automate data updates with Python scripts  
- Add predictive analytics for race outcomes  
- Integrate live F1 data streams for real-time dashboards
